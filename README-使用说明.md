# 我的观影小站 · 使用说明

一个完全在你电脑上运行的个人观影卡片墙。数据不上云、不联网也能看（只有「自动匹配海报」这一步需要联网：先问豆瓣，豆瓣不给就改从百度图片找）。

---

## 一、怎么打开（三步）

1. 打开文件夹 `我的观影小站`。
2. **双击 `启动.bat`**。
3. 稍等两秒，浏览器会自动打开页面。（会弹出一个黑色窗口，别关它，用完再说。）

黑色的窗口 = 网页的"后台"。**关掉它就是停止服务**；你的数据、海报都还在硬盘上，下次双击 `启动.bat` 又是原样。

> 第一次点开页面会看到黑幕上的「点击启幕」按钮。点一下，序幕与钢琴声一起开始（浏览器规定：必须先点一下才能出声）。

## 二、页面上能做什么

| 想做的事 | 怎么做 |
|---|---|
| 移动卡片墙 | **按住画面拖**，松手会自己滑行一段（有惯性）。也可以用滚轮、方向键 |
| 看某一部详情 | **点卡片**。里面有豆瓣评分 / 我的评分 / 导演主演 / 我的评论，还有「在豆瓣查看」按钮 |
| 换这张卡片的海报 | 鼠标移到卡片上，点右上角的小图片图标 → 弹窗里可以**自动匹配**或**手动上传** |
| 找任意一条收藏 | 顶部搜索框（快捷键 `Ctrl + K` 或 `/`）→ 全库 **2402 条**都能搜到 |
| 把搜索到的条目放上墙 | 搜索结果右侧点「加入卡片墙」（再点一次是「移出卡片墙」） |
| 换排序 | 顶部「最近添加」按钮，循环切换：最近添加 → 我的评分 → 豆瓣评分 → 随机排布 |
| 随便逛逛 | 顶部「随机漫游」，会带你飞到墙上随机一张卡片 |
| 自己加一条 | 顶部「添加」→ 填标题，豆瓣链接选填 → 「保存并加入卡片墙」 |
| 重看开场 | 顶部最右边的圆形箭头「重播序幕」 |

关于卡片墙（2026-09-28 起）：

- 卡片墙现在**默认收录全库所有条目**（2402 条），没海报的先显示兜底封面，之后可以逐张手动补海报。
- 卡片以**立体随机**方式散布成一片「卡片云」：每张卡有自己的深度、朝向和位置，拖动时有真实纵深感。
- 为了流畅：网页**只渲染视口附近的二三十张卡片**，拖到哪儿就动态换哪儿（虚拟渲染），2000+ 张也一点不卡。
- 背景会不定期飘出一些电影史经典台词，看看你认得出几部。

小技巧：

- 海报弹窗里，**直接把图片拖进去**，或者复制一张图后 **Ctrl + V 粘贴**，都能上传。
- 上传的图片会自动压成小尺寸 `webp`（质量几乎看不出差别，体积小很多），存在 `assets\covers\` 里。
- 详情弹窗里按 `←` `→` 可以在当前结果里翻上一条 / 下一条，`Esc` 关闭。

## 三、数据从哪来、怎么更新

- 数据来自你导出的豆瓣 Excel（`data\豆伴(46910768).xlsx`）。
- 想更新：把新的 Excel 放进 `data\` 目录，然后**双击 `更新数据.bat`**。它会：
  1. 重新读 Excel，重写 `data\library.js`（全量条目）；
  2. 把新出现的 **5 星条目**的海报补抓下来。
- **已经抓过的不会重复抓**（脚本有缓存），所以重复运行很安全。
- 豆瓣没有官方 API，脚本做得很保守（单线程、每次间隔 3–6 秒）。如果短时间内被豆瓣限流，它会**自动停下保护你的 IP**，这时隔 1 小时以上再运行一次就行，会接着补。

> 只补上次失败的那几张（走豆瓣）：在文件夹里按住 `Shift` 右键 →「在此处打开 PowerShell」→ 输入
> `python tools\fetch_covers.py --only-failed`
>
> 豆瓣被封了想换个来源补（走百度图片，不会封 IP）：
> `python tools\fetch_covers.py --from-baidu`

## 四、文件都放在哪

```
我的观影小站\
├─ 启动.bat                ← 双击这个开始用
├─ 更新数据.bat            ← 换了 Excel 之后双击这个
├─ index.html              ← 网页本体（其实双击它也能看，只是没有服务=只读模式）
├─ data\                   ← 数据
│   ├─ library.js            全量条目（脚本生成，别手改）
│   ├─ featured.json         卡片墙成员（网页里加/减会写到这里）
│   └─ custom_items.json     你在网页里新增的条目
├─ assets\
│   ├─ covers\             ← 所有海报都在这里（约 20KB 一张）
│   ├─ css\js\vendor\      ← 样式、脚本、本地库
└─ tools\                  ← 抓取与服务的 Python 脚本
```

**整个文件夹拷到别的电脑（或 U 盘）就能用**，不依赖网络。

## 五、常见问题

**Q：页面顶上出现黄条「只读模式」？**
说明没连上本机服务。请关掉这个页面，改为**双击 `启动.bat`** 打开。只读模式下仍可浏览，但不能保存、不能匹配/上传海报。

**Q：点「自动匹配海报」报错？**
它会先试豆瓣，豆瓣走不通（网络不通或被临时限制）就自动改从**百度图片**找一张最像海报的（竖版、2:3 比例）。两边都失败才会报错，弹窗里会说明原因，这时直接用「手动上传」自己选一张图就行，效果一样。

**Q：我不小心把某张卡片移出墙了，怎么加回来？**
顶部搜索框搜它，结果行右侧点「加入卡片墙」。

**Q：上传的海报想还原？**
海报弹窗里点「恢复默认」，会删掉你上传的图；之后跑一次 `更新数据.bat` 会自动重新抓官方海报。

**Q：黑色窗口提示「端口 8765 被占用」？**
说明之前已经开着一个。先关掉旧的黑色窗口，再双击 `启动.bat`。

**Q：双击 `启动.bat` 一闪而过？**
说明电脑没装 Python。去 [python.org](https://www.python.org/downloads/) 下载安装，安装时务必勾选 **Add Python to PATH**，然后重新双击。
